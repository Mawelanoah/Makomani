# Mukomani Website

Mobile-first website for **Mukomani** — Chicken, Sphatlo, Hake & Bakery.

Dark theme with red accents and WhatsApp ordering + cart system.

## Features

- Fully responsive
- Open / Closed status (07:30 – 18:00)
- Cart with quantity support
- WhatsApp order message (name + phone + items + total)
- Smooth scroll + mobile menu
- Google Maps link

1. Go to https://app.netlify.com/drop
2. Drag & drop the whole `mukomani` folder
3. Get an instant live link

### GitHub Pages
1. Create a new repo
2. Upload the contents of the `mukomani` folder
3. Enable Pages in Settings
